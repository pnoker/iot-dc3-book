### 1.2 直接迁移的组件

- `HeroWaves.vue` + `HeroParticles.vue` —— 首页 Hero 背景动效（粒子 + 波浪）。**保留**（已确认），仅注入首页 `home-hero-before` slot，**不进阅读页**，避免干扰长文阅读。
- `HeroLogo.vue` —— 首页 Hero 主图位；若主图位已被 `BookCover` 占据则可省略。
- `GlobalCursor.vue` —— 全局光标特效；阅读站建议**关闭**（干扰阅读）。
- glass nav（毛玻璃导航栏）—— `style.css` 已覆盖 `.VPNavBar`，迁移即得。

### 1.3 online 的视觉调性参考

### 3.2 图表呈现与放大

- 架构图（`figures/chapter-XX/fig-XX-YY.png`）用转换层输出的 `<figure class="fig">` 包裹，居中、带图题（图 N-M　说明）。
- **点击放大**：用 `medium-zoom` 绑定 `.vp-doc img`（排除 `.no-zoom`）。背景跟随主题色，ESC/点击空白关闭。
- 章扉页（`dividers/chapter-XX.png`）加 `no-zoom`，作纯装饰。
- 大图在窄屏自动等比缩放，不溢出。

### 3.3 阅读体验微调（在 online CSS 基础上为「书」加的一点）

- 正文最大宽 `~760px`（online `VPDoc .content-container` 已限 `900px`，阅读可再收窄一点提升单行可读性）。
- 段落首行缩进 2em（中文书习惯，**已确认采用**）：基础规则 `.vp-doc p { text-indent: 2em }`，再用选择器**排除非正文段落**——列表项 `<li>`、blockquote、代码块、`<figcaption>`、`<figure>` 内文字、紧跟标题或图片的首段。实现时按实际渲染 DOM 验证选择器，确保只有正文段落缩进。
- 代码块、表格样式沿用 online（已很完善）。
- 术语首次出现的加粗解释（书里大量存在）保持 `**…**`，无需特殊处理。

## 4. 图表放大（medium-zoom）实现

```ts
// .vitepress/theme/index.ts
import mediumZoom from 'medium-zoom'
import { onMounted, watch, nextTick } from 'vue'
import { useRoute } from 'vitepress'

export default {
  ...DefaultTheme,
  setup() {
    const route = useRoute()
    const initZoom = () =>
      mediumZoom('.vp-doc img:not(.no-zoom):not(figure.chapter-divider img)', {
        background: 'var(--vp-c-bg)',
        margin: 24,
      })
    onMounted(initZoom)
    watch(() => route.path, () => nextTick(initZoom))   // 路由切换后重绑
  },
}
```

> `medium-zoom` 是 VitePress 官方文档站同款方案，体积小、无 SSR 问题、自动适配暗色。
> 排除两类图：章扉页（`chapter-divider`）、显式 `no-zoom`。

## 5. 三端响应式

复用 online 断点（`1280 / 960 / 640`），每端布局：

| 断点 | 布局 | 细节 |
|---|---|---|
| **桌面 ≥1280px** | 左 sidebar + 正文 + 右 outline（三栏） | 全展开；sidebar 篇可折叠；图放大、表格全宽 |
| **平板 768–1279px** | 左 sidebar（可滑出）+ 正文 | outline 收进「本页」抽屉或顶部；图自适应 |
| **手机 <768px** | 汉堡菜单 + 单栏正文 | sidebar 抽屉化；字号自适应（online `VPDoc h1` 已分档）；**表格横向滚动**（online 已 `overflow-x:auto`）；图等比缩放可点击全屏放大 |

关键：online 的 `style.css` 已为三档 `VPDoc h1`、`VPDoc table`、`VPHero` 写好响应式规则，**迁移即得三端基础**，再针对阅读微调。
